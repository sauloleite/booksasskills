# booksasskills

Technical books turned into agent skills: one folder per book, one skill per chapter, plus a whole-book skill. Skills are original syntheses (decision frameworks, playbooks, checklists) and do not reproduce the books' text.

## Books

- [AI Engineering, Chip Huyen](ai-engineering-chip-huyen/)
- [Building Applications with AI Agents, Michael Albada](building-applications-with-ai-agents-albada/)
