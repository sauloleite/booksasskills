# booksasskills

Technical books turned into agent skills: one folder per book, with skills per chapter, per theme and for the whole book. Skills are original syntheses (decision frameworks, playbooks, checklists) and do not reproduce the books' text.

## Books

- [AI Engineering, Chip Huyen](ai-engineering-chip-huyen/)
- [Building Applications with AI Agents, Michael Albada](building-applications-with-ai-agents-albada/)
- [Fundamentals of Software Engineering, Nathaniel Schutta and Dan Vega](fundamentals-of-software-engineering-schutta-vega/)
